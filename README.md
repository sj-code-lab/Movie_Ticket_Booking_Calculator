# Movie Ticket Booking Calculator

A Python project developed as part of the freeCodeCamp Python Certificate workshop. This script calculates the final price of a movie ticket based on various conditions such as age eligibility, membership status, show times, weekends, seat types, discounts, and extra charges.

## Features

* **Eligibility Checking**: Validates user age against minimum requirements for general booking and evening shows.
* **Discounts & Surcharges**: Applies membership discounts and handles extra charges for weekend or evening viewings.
* **Dynamic Pricing**: Calculates service charges depending on the selected seat type (e.g., Premium, Gold).
* **Final Price Calculation**: Computes the total ticket cost by factoring in the base price, extra charges, service charges, and applicable discounts.
